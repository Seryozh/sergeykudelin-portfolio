# Sergey Kudelin portfolio

A source-bounded portfolio built around two cases: FutureClinic and Fyxed. The
public site on `main` stays untouched while this replacement is developed on
`redesign/futureclinic-fyxed`.

## Local development

```bash
npm ci
npm run dev
```

## Verification

```bash
npm test
```

The preview is intentionally `noindex`. Publishing requires a separate approval
for the final resume, Fyxed wording, analytics vendor, indexing, and production
deployment.
