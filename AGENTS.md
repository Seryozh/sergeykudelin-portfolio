# Portfolio implementation contract

Read the four files in `design/` before changing a visible surface.

The public page starts inside the Fyxed repair contradiction. It presents owner-paid financing as Sergey's proposed product and GTM thesis. It does not present that path as a shipped mechanism.

## Non-negotiable rules

1. Keep the Fyxed repair interruption as the first composition. No generic hero may precede it.
2. Keep FutureClinic structurally separate from Fyxed.
3. Put public case content in `content/site.json`.
4. Keep unsupported outcomes, quotes, dates, totals, and metrics out.
5. Keep the two Fyxed programs distinct.
6. Use cobalt only for Sergey's proposed correction.
7. Keep the complete story visible in base server-rendered CSS. Interactive hiding begins only after hydration.
8. Preserve keyboard, touch, reduced-motion, print, and failed-JavaScript paths.
9. Do not add a reusable case shell, public taxonomy, state counter, route legend, case number, faux evidence, fake artifact, display serif, mono chrome, gradient, rounded card, bento grid, scroll reveal, parallax, custom cursor, or decorative animation.
10. Do not use rule-of-three marketing phrasing.

Run `npm run validate:design`, `npm run typecheck`, `npm run lint`, `npm run build`, and `npm test` before handoff.
